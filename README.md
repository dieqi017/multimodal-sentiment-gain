# multimodal-sentiment-gain

多模态情感分析研究代码仓库。首阶段为 S0：比较文本单模态与三模态模型，分析音频、视觉的补充收益。

## 当前状态

仓库已初始化，实验方案正在审阅，尚未实现模型或产生实验结果。骨干候选为中文 RoBERTa、WavLM 和 ViT；数据计划使用 CH-SIMS v2 的有标注部分。具体配置以审阅后的实验协议为准。

## 开发与实验

本地用于代码开发和小样本调试，学校 HPC 用于正式训练与评价。后续实验代码、脚本与配置统一在本仓库维护。

建议在进入实现阶段时按需建立以下目录，不预先填入未验证的实现：

| 目录 | 用途 |
|---|---|
| `src/` | 数据读取、模型及训练/评价逻辑 |
| `configs/` | 不含凭据和机器私密路径的实验配置 |
| `scripts/` | 预处理、调试、训练及 HPC 作业入口 |
| `tests/` | 必要的正确性检查 |
| `docs/` | 可公开的代码使用说明 |

数据集、原始音视频、特征、预训练权重、checkpoint、缓存和运行产物通过本地路径引用，不上传 GitHub。配置示例应使用占位路径，不写入凭据。

## S0 收益口径

对同一样本、同一个多模态情感标签，计算 `delta_add = abs(pred_T - y) - abs(pred_TAV - y)`。正值表示三模态误差更小，负值表示文本单模态误差更小。

该值用于诊断信息补充，后续主导路径切换收益需要另行定义和验证。
